# Timesheet Project

This repository contains a **Timesheet** web application / spreadsheet that helps track working hours, clock-in/clock-out times, and calculates total hours worked.  

## 🚀 Features
- Record **Date**, **Clock In**, **Clock Out**  
- Automatic calculation of **Work Hours**  
- Organized in an easy-to-read table format  
- Can be exported/downloaded for reporting  

## 📂 Project Structure
- `index.html` → Main page of the timesheet  
- `style.css` → Styling (if applicable)  
- `script.js` → Logic for calculations (if applicable)  
- `Time Card.xlsx` → Excel version of the timesheet (if included)
